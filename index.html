一個新的開始，延續原本的一切

Tokel Genesis 是 TokelPlatform 的社群延續。原團隊的貢獻永遠保留在歷史中；所有舊錢包、代幣、餘額完全相容，鏈上資料一點都沒變。

Tokel Genesis is a community continuation of TokelPlatform. The original team's contributions remain in the history forever. All existing wallets, tokens and balances are fully compatible, and nothing on-chain has changed.

常見問題

你可能想知道

Tokel Genesis 是官方 TokelPlatform 嗎？

不是。它是社群延續：延用同一條鏈與原始程式碼（完整保留原作者與歷史），並持續修正與更新。

我需要做什麼才能保住我的 TKL？

什麼都不用做。你的 TKL、代幣與 NFT 都在原本的地址上。請小心任何要求你「遷移」或「領取」的訊息，那都是詐騙。

鏈為什麼曾經停止？

原團隊停止營運後，沒有人繼續挖礦，區塊就停了。現在有人持續挖礦，鏈已恢復正常出塊，資料完全沒有改變。

我可以參與挖礦嗎？

可以。Tokel 使用 Equihash，用一般電腦的 CPU 就能挖。請參考「運行節點與挖礦」的說明。

tokel.io 怎麼打不開？

那是原團隊的網域，主機已停止服務。Tokel Genesis 的新家就是這個網站與 GitHub 上的 TokelGenesis。
