# tokelgenesis.github.io

Tokel Genesis｜Γένεσις｜創世紀・新篇章：the website of the community continuation of TokelPlatform.

Plain HTML, CSS and JS: no build step, no framework, no third-party scripts, no cookies, no tracking.
Bilingual (繁體中文 / English), light and dark mode, installable as an app (PWA) on iPhone, iPad and Android.

- `index.html`: page content (Chinese text inline, `data-i18n` keys)
- `app.js`: English texts, language switch, phone menu, copy e-mail, offline support
- `styles.css`: design
- `sw.js`, `manifest.webmanifest`: offline and "add to home screen"
